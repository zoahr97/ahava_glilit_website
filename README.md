# Ahava Glilit – Vacation Cabins Website

**Academic grade: 96/100**

A front-end promotional website for **Ahava Glilit**, a vacation cabin complex in the Galilee. The website presents the accommodation options and helps visitors explore the cabins, view their features, check prices, and contact the business.

The site includes a home page with an introduction to the complex, dedicated pages for each accommodation option, image galleries, a promotional video, a pricing page, and a contact page. It also provides direct links to the business’s social media channels and a convenient WhatsApp link for reservations.

The website was designed with a consistent visual style and clear navigation between pages, creating an inviting browsing experience that reflects the relaxing and luxurious atmosphere of the cabins.

## Key Features

- Home page introducing the vacation complex
- Dedicated pages for different cabins and suites
- Image galleries for each accommodation option
- Promotional video
- Pricing page with weekday and weekend rates
- Contact information and direct WhatsApp reservation link
- Links to Instagram, Facebook, and YouTube
- Shared navigation bar and footer across pages
- Organized and separated HTML, CSS, image, and video resources

## Technologies

**Frontend:** HTML, CSS  
**Media:** Images and video  
**Tools:** Git and GitHub
